# План: уравнения Максвелла и ЭМ-волны (3D FDTD)

Отдельный движок ЭМ-поля рядом с цепным MNA-солвером. НЕ трогает `CircuitSolver`.
Решает полную систему Максвелла (роторные уравнения с током смещения) методом
FDTD (Finite-Difference Time-Domain, сетка Йи, чехарда E/H).

## Решение по архитектуре

- **Симуляция:** 3D, сетка Йи (6 компонент: Ex,Ey,Ez,Hx,Hy,Hz на смещённой сетке).
- **Визуализация:** подвижные ортогональные **срез-плоскости** через объём, heatmap
  (viridis, как `ColorMaps.h`), загрузка в GL-текстуру и вывод (путь `LICFieldRenderer`).
  Объёмный рендер — НЕ делаем (текущий рендер ImGui-2D/GL 1.1).
- **Поглощение границ:** Этап 1 — graded-σ sponge (просто, устойчиво). Этап 3 — CPML.
- **Чистота:** движок без зависимостей от UI/GL, покрыт gtest (скорость волны ≈ c,
  устойчивость, симметрия источника).

## Уравнения (СИ, относительные ε_r, μ_r=1)

```
dt = courant · ds / (c·√3),  c = 1/√(μ₀ε₀)
H -= (dt/μ₀)·(∇×E)
E  = ca·E + cb·(∇×H),  ca,cb из ε_r и σ (потери/поглощение)
PEC: E=0 в маске проводника
```

## Этапы

- **Этап 1 — Ядро (СЕЙЧАС).** `src/physics/FdtdField.h` (header-only, inline):
  сетка Йи, обновление E/H, материалы (ε_r, σ, PEC-маска), мягкий источник,
  graded-σ граница, доступ к срезам. `tests/test_fdtd.cpp`: скорость фронта ≈ c,
  отсутствие NaN/взрыва за N шагов, симметрия точечного источника.
- **Этап 2 — Источники и сцены.** Мягкий источник, TFSF-плоская волна; `EmScene`/
  `EmDemo`-перечисление. Демки:
  1. Точечный/дипольный излучатель — расходящиеся волны, диаграмма направленности.
  2. Две щели — интерференция/дифракция (плоская волна + PEC-экран с щелями).
  3. Отражение/преломление — граница сред (разные ε), Снеллиус, стоячая волна у PEC.
  4. Волновод/резонатор — канал между PEC-стенками, моды, резонанс полости.
- **Этап 3 — Рендер и режим UI.** Срез-плоскости + текстура; новый режим «ЭМ-поле»
  (вкладка/canvas), выбор плоскости (XY/XZ/YZ) и позиции, поле Ez/|E|/энергия.
  CPML вместо sponge для чистых излучателей.
- **Этап 4 — Практикум.** Снять `--capture` ЭМ-сцен, дописать главу теории
  (Максвелл, ток смещения, волны, c=1/√(μ₀ε₀), интерференция, волноводы) + работы.

## Риски / честные ограничения

- **Производительность:** 3D в реальном времени ограничивает сетку (~80³–128³,
  одно ядро C++). Возможна многопоточность по срезам позже.
- **Память:** ~6+3 float-полей на ячейку.
- **Граница:** sponge даёт небольшие отражения; для «чистого» излучателя нужен CPML (этап 3).
- **Не входит:** дисперсия/нелинейные среды, 3D-объёмный рендер.
