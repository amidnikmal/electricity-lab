# Физические модели и приближения проекта Current Lab

В этом документе явно перечислены все физические приближения, используемые
на разных уровнях моделирования.

---

## Уровень 1: Схемная модель (Lumped Circuit)

### Что моделируется
- Цепь как граф узлов и двухполюсных компонентов.
- Каждый компонент описывается одним уравнением (закон Ома, Кирхгоф).
- DC steady-state и переходные процессы (transient) с линейными C и L.

### Математическая модель
- Модифицированный узловой анализ (Modified Nodal Analysis, MNA).
- Неизвестные: потенциалы узлов + токи через источники напряжения.
- Линейная система Ax = b.
- Для transient: companion-модели C/L (Backward Euler/Trapezoidal),
  интегрируемые в MNA-матрицу на каждом временнóм шаге.

### Уравнения
- KCL: Σ I_k = 0 в каждом узле (кроме reference).
- Резистор: I = (V_a − V_b) / R → проводимость g = 1/R.
- Источник напряжения: V_a − V_b = V_source → дополнительное уравнение.
- Reference node: V_ground = 0 (по определению).
- Конденсатор C: g = C/dt, ieq = (C/dt)·Vc(t) (Backward Euler companion).
- Катушка L: g = dt/L, ieq = −Il(t) (Backward Euler companion).
- Диод/ключ: кусочно-линейная модель с численными Ron, Roff, gmin.

### Приближения
1. **Сосредоточенные параметры (lumped)**: длина проводов много меньше
   длины волны (λ ≫ L).
2. **Идеальные провода**: сопротивление, индуктивность и ёмкость проводов
   не учитываются (см. Уровень 2 для distributed wire).
3. **Линейные пассивные элементы**: R, C, L не зависят от напряжения/тока.
4. **Дискретизация по времени**: O(dt) для BE, O(dt²) для трапеций.
5. **Отсутствие температурных эффектов**: сопротивление не зависит
   от нагрева.

### Что является физически точным
- Законы Кирхгофа (следствие закона сохранения заряда и потенциальности
  электрического поля в квазистатике).
- Закон Ома для омических материалов при заданной температуре.
- Энергетический баланс (Tellegen) на каждом шаге transient.

### Что НЕ является физически точным
- Реальные провода всегда имеют конечное сопротивление.
- При больших токах нагрев меняет сопротивление.
- На высоких частотах проявляются индуктивность и ёмкость проводов,
  скин-эффект.
- Нелинейные C/L, взаимная индуктивность, AC-источники не моделируются.

## Уровень 2: Распределённый провод (Distributed Wire)

### Что моделируется
- Провод как цепочка из N малых резисторов (`Circuit::toDistributed`).
- Потенциал вычисляется в каждой точке вдоль провода.

### Математическая модель
- Дискретизация: провод длиной L разбивается на N сегментов.
- Сопротивление сегмента: R_seg = ρ · (L/N) / A.
- Решается система уравнений для потенциалов в точках дискретизации.

### Уравнения
- R_total = ρ · L / A.
- Для однородного провода: V(x) = V₀ − (V₀ − V_L) · x/L (линейно).
- Для цепи с большим резистором в середине: почти плоские плато
  до и после резистора, резкий спад на резисторе.

### Приближения
1. **1D модель**: учитывается только продольная координата x.
2. **Постоянное сечение**: A = const вдоль провода.
3. **Однородный материал**: ρ = const.
4. **Пренебрежение двумерными/трёхмерными эффектами поля**.

### Что является физически точным
- Линейное падение напряжения вдоль однородного проводника с постоянным
  током.
- Концентрация падения напряжения на большом сопротивлении.

### Что НЕ является физически точным
- Реальное поле E в трёхмерном пространстве вокруг провода.
- Эффекты на изгибах провода.
- Поверхностный заряд как причина поля.

## Уровень 3: Дрейф электронов

### Что моделируется (реализовано: слой Drift, `DriftModel`)
- Частицы-электроны внутри провода.
- Хаотическое тепловое движение + малый средний дрейф в направлении,
  противоположном conventional current.
- Визуализация для демонстрации разницы между скоростью дрейфа
  и скоростью распространения электрического сигнала.

### Математическая модель
- Дрейфовая скорость: v_d = I / (n · A · e).
- Тепловая скорость: v_th ∼ sqrt(kT/m).
- Для меди при комнатной температуре: v_th ∼ 1.2×10⁵ м/с, v_d ∼ 0.1 мм/с
  (при токе ∼1 А через провод сечением 1 мм²).

### Приближения
1. **Coarse-grained particles**: частицы на экране — не реальные электроны,
   а визуальные представители большого ансамбля.
2. **Усиленная скорость**: для наглядности дрейфовая скорость визуально
   увеличивается (это должно быть явно указано в UI).
3. **Одномерное ограничение**: частицы движутся внутри 1D-канала провода.
4. **Пренебрежение квантовыми эффектами**: электроны рассматриваются
   как классические частицы (модель Друде).

### Что является физически точным
- Относительное соотношение: v_d ≪ v_th.
- Направление дрейфа электронов противоположно conventional current.
- Зависимость v_d от тока, сечения и концентрации носителей.

### Что НЕ является физически точным
- Отдельные точки на экране — не траектории реальных электронов.
- Квантово-механическая природа электронов проводимости не учитывается.
- Реальная скорость на экране многократно усилена.

## Уровень 4: Электрическое поле (концептуальное)

### Что моделируется (реализовано: слой ElectricField / SurfaceCharge)
- Стрелки E-field вдоль проводника.
- Связь направления поля с направлением conventional current.

### Математическая модель
- В 1D: E_x = −dV/dx.
- Поле направлено от большего потенциала к меньшему.
- Сила на электрон: F = −e·E (против поля).

### Приближения
1. **Концептуальная 2D проекция**: не полный 3D Maxwell solver.
2. **Электростатическое приближение**: rot E = 0 (справедливо для DC).
3. **Упрощённая геометрия**: поле рассчитывается только вдоль проводов.

### Что НЕ является физически точным
- Реальное распределение поля в 3D вокруг проводников сложной формы.
- Эффекты на изгибах.
- Магнитное поле (B) и вектор Пойнтинга (S = E × H).

## Уровень 5: Мощность и тепловыделение

### Что моделируется (частично в Milestone 1, расширено в будущем)
- Мощность, рассеиваемая на каждом элементе.
- Heat map распределения мощности.

### Математическая модель
- P = I · ΔV = I²R = V²/R.
- Плотность мощности: p = J · E (джоулево тепло на единицу объёма).

### Приближения
1. **Всё тепло считается джоулевым** — нет пельтье-эффекта и т.п.
2. **Нет теплообмена с окружением** — не моделируется охлаждение.
3. **Стационарный режим** — тепловые переходные процессы не моделируются.

### Что является физически точным
- P = I·ΔV — мощность выделяется там, где одновременно есть ток
  и падение напряжения.
- На резисторе с большим R основная мощность.

### Что НЕ является физически точным
- Реальное распределение температуры (требует теплофизической модели).
- Зависимость сопротивления от температуры.

## Явный список ВСЕХ приближений (текущая версия)

1. Lumped circuit approximation.
2. Идеальные провода (R_wire = 0, эквипотенциальные) — снимается distributed wire.
3. Линейные омические элементы (R не зависит от I, T).
4. Companion-модели C/L: дискретизация по времени O(dt) или O(dt²).
5. Кусочно-линейная модель диодов/ключей с Ron, Roff, gmin.
6. 2D визуализация схемы (не реальная геометрия).
7. Квазистатическое приближение (не решаются полные уравнения Максвелла).
8. Отсутствие температурной зависимости.
9. Отсутствие скин-эффекта.
10. Отсутствие шумов (тепловой, дробовой).

## Критерии расширения модели

При добавлении нового слоя моделирования необходимо:

1. Явно указать, какие приближения добавляются/снимаются.
2. Добавить запись в этот документ.
3. Обеспечить обратную совместимость: старые тестовые схемы должны
   работать с той же точностью.
4. Добавить режим физической проверки для нового слоя.
