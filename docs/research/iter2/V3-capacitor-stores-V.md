# V3: Транзиент хранит V, а не Q — ВЕРДИКТ ПОДТВЕРЖДЁН

## Вердикт: ЛОЖНАЯ находка? НЕТ — НАХОДКА ИСТИННА.

Транзиентное состояние конденсатора хранит **напряжение V**, а не заряд Q = C·V.

## Доказательства

### 1. Поле данных: `capVoltage` (не `capCharge`)

`src/solver/CircuitSolver.h:33-36`:
```cpp
// capVoltage: Vc = V(nodeA) - V(nodeB); indCurrent: Il flowing nodeA -> nodeB.
struct TransientState {
    ...
    std::unordered_map<int, double> capVoltage;
```
Комментарий и имя поля явно говорят: хранится напряжение, не заряд.

### 2. Шаг интегратора: читает V, пишет V

`src/solver/CircuitSolver.cpp:193`:
```cpp
double vOld = state.capVoltage.count(comp.id) ? state.capVoltage[comp.id] : 0.0;
```

`src/solver/CircuitSolver.cpp:226`:
```cpp
state.capVoltage[comp.id] = br.voltageDrop;
```
Читается напряжение (`vOld`), обратно записывается `voltageDrop` (тоже напряжение, В). Нигде нет `state.capCharge = C * v` или `vOld * C`.

### 3. `onCircuitEvent` НЕ пересчитывает состояние при изменении C

`src/simulation/LiveSim.cpp:95-111` — метод `onCircuitEvent`:
- Вычисляет `smallestTimeConstant` и `oscillationTimescale` (пересчёт скорости).
- Вызывает `applySpeed()` и `wake()`.
- **Никакой миграции `capVoltage` при изменении `comp.value`.** Состояние `m_state` не трогается.

`src/simulation/LiveSim.h:67`:
```cpp
// Цепь изменилась (правка, щелчок выключателя, демка): будит солвер,
// пересчитывает авто-скорость. Состояние C/L сохраняется.
```
«Состояние C/L сохраняется» — сохраняется как есть, без пересчёта.

### 4. Что происходит с зарядом при смене C при том же V

Заряд Q = C·V. Энергия E = ½CV². При изменении C:

| До правки | После правки (C₂ = 2·C₁) | Последствие |
|-----------|--------------------------|-------------|
| V = 5 В   | V = 5 В (сохранено)       | Q₂ = 2·Q₁  |
| C₁ = 1 мкФ | C₂ = 2 мкФ               | E₂ = 2·E₁  |

Заряд и энергия **удваиваются из ниоткуда** — нарушение сохранения заряда/энергии.

### 5. Противоречие с заявленной семантикой

`src/simulation/LiveSim.h:17-18`:
```cpp
// Заряд конденсаторов ПЕРЕЖИВАЕТ правки и щелчки (это физика, а не сброс);
// обнуление — только явным discharge().
```
Заявлено: «заряд переживает правки». Фактически: хранится V, заряд Q = C·V меняется при правке C. Комментарий **не соответствует реализации**.
