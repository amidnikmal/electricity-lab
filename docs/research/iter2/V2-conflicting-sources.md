# V2: Конфликтующие идеальные источники напряжения

**Вердикт: НАХОДКА ПОДТВЕРЖДЕНА (ИСТИНА)**

## Суть

Два VoltageSource с разными значениями, подключённые параллельно между одними узлами, или контур идеальных источников с несовместимой KVL-суммой, не диагностируются. Солвер выдаёт конечный численный результат, физически бессмысленный.

## Доказательство

### 1. Отсутствие валидации перед solve

`src/solver/CircuitSolver.cpp:61-74` — штамповка VoltageSource в MNA:

```cpp
} else if (comp.type == ComponentType::VoltageSource) {
    int vsr = vsRowOffset + vsIdx;
    if (ra >= 0) { sys.A[ra][vsr] += 1.0; sys.A[vsr][ra] += 1.0; }
    if (rb >= 0) { sys.A[rb][vsr] -= 1.0; sys.A[vsr][rb] -= 1.0; }
    sys.b[vsr] = comp.value;
    ++vsIdx;
}
```

Ни до, ни после этого цикла (строки 61–90) нет **никакой** проверки:
- параллельности двух источников с разными напряжениями;
- контуров источников с несовместимой KVL-суммой;
- сингулярности/несовместности результирующей MNA-матрицы.

Весь call-stack (`solve` → `solveIterative` → `solveWithCompanions`) не содержит topology/consistency checks.

### 2. Gaussian elimination молча пропускает нулевой pivot

`src/math/LinearSystem.h:27`:

```cpp
if (std::abs(M[pivot][col]) < 1e-15) continue;
```

При вырожденной системе строка с нулевым pivot просто пропускается (`continue`), без ошибки или предупреждения. Уравнение-ограничение «теряется», и солвер возвращает одно из бесконечного множества решений как конечный результат.

### 3. Трассировка для 5V‖3V (nodes 0 и 1, ground=0)

MNA-система 3×3 для V₁, I₁, I₂:

```
[0  1  1] [V₁]   [0]     — KCL node 1
[1  0  0] [I₁] = [5]     — VS1: V₁ = 5
[1  0  0] [I₂]   [3]     — VS2: V₁ = 3
```

После исключения Гаусса:

```
[1  0  0] [V₁]   [ 5]
[0  1  1] [I₁] = [ 0]
[0  0  0] [I₂]   [-2]
```

Pivot для третьего столбца нулевой — `continue`, столбец пропущен. Результат:

- **V₁ = 5V** (ограничение VS1 выполнено)
- **I₁ = 0A**, **I₂ = −2A**
- Ограничение VS2 (V₁ = 3) отброшено

Физически: два идеальных источника 5V и 3V в параллель — это короткое замыкание с бесконечным током. Солвер возвращает конечные 0A и −2A без каких-либо признаков проблемы.

### 4. Существующий тест не покрывает конфликт

`tests/test_solver.cpp:401-414` — `ParallelVoltageSourcesProducesFiniteResults`:

```cpp
c.addComponent(ComponentType::VoltageSource, 1, 0, 5.0);
c.addComponent(ComponentType::VoltageSource, 1, 0, 5.0);  // одинаковые!
```

Тест использует два **одинаковых** источника (оба 5V) — вырожденный случай, где система совместна и V₁ = 5V действительно корректно. Название теста («produces finite results») трактует конечность как успех, маскируя проблему.
